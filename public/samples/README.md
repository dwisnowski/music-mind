# Built-in practice scores (Quick start)

Bundled for offline / first-run use. The in-app **MuseTrainer library** browser loads the rest of the catalog live from [musetrainer.github.io/library](https://musetrainer.github.io/library/) (see [ADR 0005](../../docs/adr/0005-musetrainer-remote-library.md)).

| File | Piece | Source |
| --- | --- | --- |
| `twinkle.musicxml` | Twinkle Twinkle (excerpt) | Project sample |
| `fur-elise.mxl` | Beethoven — Für Elise | [MuseTrainer public-domain library](https://github.com/musetrainer/library) (`Fur_Elise.mxl`) |
| `clair-de-lune.mxl` | Debussy — Clair de Lune | [MuseTrainer public-domain library](https://github.com/musetrainer/library) (`Clair_de_Lune__Debussy.mxl`) |
| `gymnopedie-no1.mxl` | Satie — Gymnopédie No. 1 | [MuseTrainer public-domain library](https://github.com/musetrainer/library) (`Erik_Satie_-_Gymnopedie_No.1.mxl`) |

Beethoven, Debussy, and Satie works are public domain. MuseTrainer redistributes MusicXML editions for practice apps.
